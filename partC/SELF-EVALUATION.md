# SELF-EVALUATION

## 1. Хэрэв шалгалт өнөөдөр болбол би энэ кодыг өөрөө бичиж чадах уу?
Үгүй. Кодыг бүтнээр нь шууд өөрөө бичихэд хэцүү байна. Ялангуяа test бичих, mock ашиглах, endpoint-уудын холбоосыг зөв тохируулах зэрэг хэсгүүд дээр AI-аас асууж ойлгох хэрэгтэй байсан. Гэхдээ AI-ийн тусламжтайгаар би кодын бүтэц, ажиллах зарчим, ямар хэсэгт ямар логик хэрэгтэйг илүү сайн ойлгосон.

## 2. Дахин хийнэ гэвэл юуг өөрөөр хийх вэ?
Дахин хийвэл test-үүдийг зөвхөн AI-гаар шууд бичүүлэхгүй, өөрөө эхлээд жижиг хэмжээгээр зохиож, дараа нь AI-аар шалгуулж засуулах байсан. Мөн repository бүтэц, package organization-ийг эхнээс нь илүү цэгцтэй төлөвлөж хийх байсан. Ингэснээр дараа нь алдаа бага гарах байсан.

## 3. Энэ туршлагаас юу сурсан бэ?
Энэ туршлагаас REST API хэрхэн ажилладаг, controller-service-repository бүтэц яаж холбогддог, unit test болон mock test-ийг яаж ашигладаг талаар бага зэрэг ойлгосон. Мөн test-ийг илүү зөв, цэгцтэй бичиж болохыг мэдсэн. AI нь хурдан тусалдаг ч кодын логикийг өөрөө эхлээд ойлгож байж л юу хийх хэрэгтэйг , юу хийхийг зөв чиглүүлж хийнэ гэдгийг ойлгосон.
