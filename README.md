# Personal Task Tracker

## Төслийн танилцуулга

Энэхүү төсөл нь Java Spring Boot ашиглан хөгжүүлсэн Personal Task Tracker backend систем юм. Хэрэглэгч task үүсгэх, харах, засах, устгах болон priority-аар шүүх боломжтой REST API систем боловсруулсан.

Төслийн зорилго нь Spring Boot architecture, REST API хөгжүүлэлт, unit testing болон AI-assisted software construction workflow сурах байсан.

---

## Ашигласан технологи

- Java 17
- Spring Boot 3
- Maven
- H2 Database
- JUnit 5
- Mockito
- Postman
- Git & GitHub

---

## Үндсэн боломжууд

- Task нэмэх
- Task жагсаалт харах
- Task засах
- Task устгах
- Priority-аар filter хийх
- REST API endpoint ашиглах
