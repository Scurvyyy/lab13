# Stack Comparison

## Option 1: Node.js + Express
+ Хялбар, хурдан хөгжүүлэлт
+ AI support сайн
- Structure сул

## Option 2: Java Spring Boot
+ Strong architecture (MVC)
+ Enterprise level
+ Security сайн
- Complexity өндөр
- Setup удаан

## Option 3: MERN
+ Full JavaScript
+ Modern
- MongoDB relational биш

## Decision
Java Spring Boot-ийг сонгосон.
Учир нь энэхүү stack нь MVC архитектур ашигладаг бөгөөд scalable, maintainable систем хөгжүүлэхэд тохиромжтой.

## Reason

- Backend хөгжүүлэлтийн мэдлэгээ гүнзгийрүүлэх
- MVC архитектурын ойлголтыг практик дээр хэрэгжүүлэх
- Scalable system бүтээх чадвар хөгжүүлэх
- Enterprise түвшний framework ашиглаж сурах
