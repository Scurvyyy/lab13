# Personal Task Tracker

## Төслийн танилцуулга
Энэхүү төсөл нь Java Spring Boot ашиглан хөгжүүлсэн Personal Task Tracker backend систем юм.
Хэрэглэгч task үүсгэх, засах, устгах болон priority-аар шүүх боломжтой.

## Үндсэн боломжууд
- Task нэмэх
- Task харах
- Task засах
- Task устгах
- Priority ашиглан filter хийх

## Хамрах хүрээ
Төсөл нь REST API backend хөгжүүлэлт болон AI-assisted software construction workflow дээр төвлөрсөн.
